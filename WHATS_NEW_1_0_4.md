# Home Finance 1.0.4 — what's new

- **Search & filters** (Transactions): search note, category, member, account or amount; filter by Income / Expense /
  Transfer and by member; toggle deleted entries; export what you see as CSV.
- **Monthly budgets** (More → Monthly Budgets): set a limit per expense category. Home shows progress bars
  (orange at 80%, red when over).
- **Recurring entries** (More → Recurring Entries): monthly or weekly rent, salary, EMIs, subscriptions. They post
  when you open the app on/after the due date. Use on ONE phone only (not synced by Wi-Fi Sync).
- **CSV export**: Reports page (CSV button), Transactions page, and More → Export All Transactions.
- **Backup health banner** on Home: warns if there is no backup outside the phone, or none for 7+ days, or Drive has a problem.
- Includes all 1.0.3 Google Drive fixes.

No database change: budgets and recurring rules live inside the database file's settings table, so every backup/restore keeps them.
